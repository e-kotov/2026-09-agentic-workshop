# Cumulative participant project

This safe, source-free project starts in Lab 1 and accumulates controls through Labs 2–4. Lab 1 supplies `data/metadata.csv` and a provenance note; Lab 2 adds tests, Git checkpoints, and a build manifest; Lab 3 reviews this boundary while keeping attack fixtures isolated; Lab 4 adds logs, decisions, and a fresh-session handoff. Use only fake data.
