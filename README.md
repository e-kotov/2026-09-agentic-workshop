# LLM Coding Agents for Research (September 2026)

## Overview

This repository contains the materials for the workshop **"Beyond the Chatbox: LLM Coding Agents for Research"** (September 2026), organized by [Egor Kotov](https://www.ekotov.pro) ([TU Dortmund University](https://www.tu-dortmund.de/en/), [Universitat Pompeu Fabra](https://www.upf.edu/en/web/politiques/home), [Max Planck Institute for Demographic Research](https://www.demogr.mpg.de/en/)).

## Repository Structure

- `tutorial-website-src/`: Quarto source code for the workshop website.
- `userspace/`: Dedicated sandbox for workshop exercises.
  - `examples/`: Guided examples and reference materials.
  - `projects/`: Placeholder for participant hands-on projects.
- `data/`: Shared workshop datasets.
- `.devcontainer/`: Configuration for VS Code Dev Containers and GitHub Codespaces.
- `Dockerbuild/`: Docker configurations for pre-built container environments.
- `.github/workflows/`: CI/CD workflows for container images and website publication.
